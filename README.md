# Mediatheque

**Bibliothèque numérique de supports de cours**  
**Digital Library for Course Materials**

## Présentation | Overview

Mediatheque est un projet conçu pour organiser les matières enseignées et leurs supports de cours au format PDF. Il permet aux étudiants de retrouver plus facilement les ressources pédagogiques de leur établissement.

Mediatheque is a project designed to organize taught subjects and their PDF course materials, helping students find their school's learning resources more easily.

## Objectif | Purpose

Centraliser les documents pédagogiques et faciliter leur consultation par matière.

Centralize learning materials and make them easier to browse by subject.

## Fonctionnalités décrites | Described capabilities

- Classement des matières enseignées / Organization of taught subjects
- Association des cours aux documents PDF / Linking course materials to PDF documents
- Consultation et recherche des ressources par les étudiants / Student access and resource discovery
